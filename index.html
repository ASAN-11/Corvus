What lives in the machine

Why an open model matters

Corvus talks to a model running through Ollama on your own hardware. Your prompts go to your local server, not to a hosted AI service, and you choose which installed model answers.

Once Ollama, a model and these app files are on your machine, inference needs no internet. Corvus is local-first software; the model itself has its own licence and limits, which you should read before commercial use. Open weights are not the same as fully open source.

Install and run

  1. Install Ollama from ollama.com and start it.
  2. Pull a Gemma model (this downloads several GB; only run it if you agree): ollama pull gemma3. Check ollama.com/library for current Gemma tags.
  3. Start Corvus. Needs Python 3.8+, no packages. Run scripts/start.sh (macOS/Linux) or scripts\start.bat (Windows). It serves the app on 127.0.0.1 only and proxies a short allow-list of Ollama routes, which avoids browser CORS problems.
  4. Install as an app from your browser's install button (PWA). A PWA is a windowed web page, not a native executable; it caches the app shell only, never model weights.
  5. Troubleshooting: open Runtime → Test connection. "Disconnected" means Ollama isn't running or OLLAMA_HOST is wrong. "Model unavailable" means nothing is pulled yet. Opening index.html as a file:// page will not work; use the launcher.

Config: environment variables OLLAMA_HOST (default http://127.0.0.1:11434) and PORT (default 8734). Health check: /health.

About the machine
Corvus is a local-first AI workspace built with plain HTML, CSS, JavaScript and a small Python launcher. It streams chat from Ollama's /api/chat using an open-weight model such as Gemma. Conversations stay in your browser. Limits: you need enough RAM/VRAM for the model, browsers restrict direct local requests, and open-weight is not fully open source. Day-of-the-Dead imagery here is meant as a nod to remembrance, not horror.
Architecture: index.html + js/app.js → server/server.py (loopback, route allow-list) → Ollama.
